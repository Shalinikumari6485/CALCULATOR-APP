# Java Swing Calculator 🖩

A simple **GUI calculator** built using **Java Swing** that performs basic arithmetic operations such as addition, subtraction, multiplication, and division. This project demonstrates the use of **Swing components**, **event handling**, and **basic arithmetic logic** in Java.


## 🔹 Features

- Addition (+), Subtraction (-), Multiplication (*), Division (/)  
- Decimal point support  
- Clear (C) and Delete (Del) functionality  
- Error handling (e.g., division by zero)  
- Easy-to-use GUI interface
